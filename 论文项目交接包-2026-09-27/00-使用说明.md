# 曹子建 2027届毕业论文项目交接包

整理日期：2026-09-27。用途：在新项目中继续宁波工程学院高等学历继续教育本科毕业论文和学位准备。

## 如何开始

1. 新建名为“曹子建｜宁波工程学院2027届毕业论文”的项目。
2. 上传整个交接 ZIP；若平台不能读取 ZIP，先解压，上传本包 Markdown 和 `原始材料` 内四份文件。模板 ZIP 的内层文件另放在 `展开模板`，方便直接上传。
3. 将 `02-新项目启动Prompt.md` 全文复制到新项目第一条消息。它也可作为项目说明的基础。
4. 新项目先核对材料和当前选题进度，再协助选题；不能凭交接摘要直接写出一篇带虚构数据的成稿。

本包只包含与论文、毕业及学位有关的上下文，不收入无关的移民、收入和软件项目聊天。包含的是结构化交接，不是逐字聊天备份。

## 内容

- `01-已知情况与学校要求.md`：个人情况、要求、时间表、冲突、缺失文件和待确认项。
- `02-新项目启动Prompt.md`：可直接使用的详细启动指令。
- `原始材料/`：四份用户提供的原文件，字节不变。
- `展开模板/`：从原模板 ZIP 提取的7份文件，保留原文件内容。
- `03-原文提取参考.txt`：三份通知/细则及模板文字的辅助提取，可能缺图片、公式及原版式。以原文件为准。
- `SHA256SUMS.txt`：包内文件校验值。

本包未替用户选择学位意向、签字、缴费或提交论文，未建立任何外部项目。原始下载文件未修改。
